# 서울이도치과 닥터인사이트 · 메인 페이지 v2

원본: https://yidoinsight.com/ · 작업일 2026-11-06

이전 A/B/C 시안은 "서브페이지를 메인에 옮겨 놓은 것 같고, 여백이 좁고, AI가 만든 티가 난다"는 피드백을 받았습니다. 그래서 세 안을 고치지 않고 메인 페이지 한 장을 처음부터 다시 설계했습니다. 사내 UI 스킬(`design-taste-frontend`)의 절차와 검수 도구를 그대로 따랐습니다.

```
yidoinsight-main/
├─ index.html     메인 페이지 (단일 파일, 외부 라이브러리 없음)
├─ assets/        병원 실사 사진 12장 + 상담 장면 루프 영상(webm/mp4)
├─ previews/      데스크톱·모바일 첫 화면과 전체 캡처
└─ README.md
```

`index.html`을 브라우저로 열면 바로 보입니다. 글꼴(Newsreader, Noto Serif KR)은 Google Fonts에서 불러오므로 인터넷 연결이 필요합니다.

---

## 1. 무엇이 달라졌나

| 이전 시안의 문제 | v2에서 바꾼 것 |
|---|---|
| 기능 블록을 나열해서 서브페이지처럼 보임 | 병원 슬로건 한 문장을 포스터 크기로 세우고, 페이지 전체를 "짧은 문장 + 근거" 리듬으로 구성 |
| 좁은 패딩과 마진 | 섹션 사이 104–200px, 페이지 좌우 여백 20–48px, 요소 사이 간격도 단계별로 통일 |
| 라벨·번호·코드·얇은 선·카드가 많음 (AI 티) | 작은 영문 라벨, 01/02 번호, 모노스페이스, 1px 구분선, 아이콘 카드, 그라데이션, 그림자를 모두 없앰. 구분은 여백과 배경 톤 차이로만 함 |
| 일러스트와 가상 이미지 | 병원에서 직접 촬영한 사진 12장과 실제 상담 장면 영상만 사용 |
| 글자 크기가 제각각 | 6단계로 통일: 14 / 18 / 24 / 36 / 68 / 118px |

## 2. 콘셉트

**"치료보다 먼저, 이해할 수 있도록."**

이 병원의 실제 슬로건을 첫 화면 전체를 채우는 문장으로 세웠습니다. 문장 안 "먼저," 뒤의 단어 자리에는 **고성민 원장이 X-ray를 보며 환자에게 설명하는 실제 영상(5초 반복)**이 들어갑니다. 읽는 사람은 "치료보다 먼저 이렇게 설명한다"를 눈으로 완성하게 됩니다.

화면은 위쪽 돌색과 아래쪽 남색, 두 면으로 나뉩니다. 문장의 두 번째 줄이 경계선에 걸리면서 위는 먹색, 아래는 밝은색으로 바뀝니다. 남색은 원장 가운에 수놓인 YIDO 로고 색에서 가져왔습니다.

## 3. 섹션 구성 (위에서 아래로)

| # | 섹션 | 하는 일 | 구성 |
|---|---|---|---|
| 1 | 히어로 | 이 사이트가 무엇인지 한 문장으로 전달 | 슬로건 + 문장 속 상담 영상 / 아래 면에 소개 문장과 **오늘 진료 상태(실시간)**·오시는 길·전화 |
| 2 | 진료 방식 | "듣고, 설명하고, 함께 결정한다" | 한 문단 안에 실제 상담 사진 3장을 단어 사이에 끼워 넣음 → 가로 전체 사진(스크롤하면 천천히 줌아웃) |
| 3 | 치아백과 | 진료실에서 들은 말을 바로 이해 | 용어 20개를 큰 글씨로 한 문단처럼 나열. **누르거나 마우스를 올리면 아래 칸에 쉬운 뜻풀이가 바로 바뀜** (이 페이지의 핵심 인터랙션) |
| 4 | 원장 칼럼 | 의료진의 관점 | 어두운 면. 왼쪽 원장 사진이 화면을 따라오고, 오른쪽 칼럼 제목에 마우스를 올리면 해당 원장 사진으로 바뀜 |
| 5 | 의료진 | 누가 무엇을 진료하는지 | 원장 사진을 문단 첫머리에 넣은 큰 소개 문단 + 상세 문단, 왼쪽에 요약 3개(의료진 4인, 전문의 2인, 원내 기공실) |
| 6 | 진료시간·위치 | 언제, 어디로 | "월요일과 목요일은 저녁 8시 30분까지." 제목 + 오른쪽 시간표(**오늘 요일 자동 강조, 진료 중·점심시간·마감 표시**) + 주소·지하철·주차 + 예약 버튼 |
| 7 | 자주 묻는 질문 | 상담 전 궁금증 | 큰 제목 아래로 들여 쓴 질문 6개. 펼치면 배경 톤이 바뀜 |
| 8 | 푸터 | 연락 | 전화번호를 큰 글씨로 크게 노출(누르면 전화 연결) + 네이버 예약·카카오톡, 주소·진료시간·언어 링크 |

## 4. 디자인 시스템

**색**

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 바탕 (돌색) | `#E4E2DD` | 기본 바탕 |
| 면 (한 톤 진한 돌색) | `#D8D5CE` | 치아백과·진료시간 섹션, 펼친 FAQ |
| 먹 | `#1C1D22` | 본문, 칼럼·푸터의 어두운 면 |
| 보조 글자 | `#55565B` | 캡션, 보조 정보 |
| 남색 (YIDO) | `#1F376F` | 예약 버튼, 히어로 아래 면 (이 두 곳에만 사용) |

**서체:** 라틴 문자와 숫자는 Newsreader, 한글은 Noto Serif KR입니다. 두 서체 모두 명조 계열이라 하나의 목소리로 읽힙니다.

**여백 규칙**
- 섹션 위아래: `clamp(104px, 12vw, 200px)`
- 페이지 좌우: `clamp(20px, 3.4vw, 48px)`
- 12칼럼 그리드, 칼럼 간격 24px
- 본문 행간 1.6, 한 줄 최대 약 40–48자
- 버튼 높이 48px 이상(모바일 44px), 모서리는 모두 직각으로 통일

**움직임**
- 히어로 문장이 한 줄씩 아래에서 올라옵니다.
- 각 섹션의 제목·본문·사진이 순서대로 나타납니다.
- 헤더 색이 아래 섹션 색을 따라 바뀝니다.
- 가로 사진이 스크롤에 따라 천천히 줌아웃됩니다.
- 칼럼 사진이 바뀔 때 겹쳐서 전환됩니다.
- 버튼은 누를 때 살짝 눌리고, 메뉴에는 밑줄이 그어집니다.
- 시스템에서 "동작 줄이기"를 켜면 이동 효과 없이 내용만 보입니다.

## 5. 검수

- 스킬 검수 도구(`lint.mjs`, `inspect.mjs`)를 1440 / 768 / 390px에서 실행해 **FAIL 0, WARN 0**을 확인했습니다. 측정 항목은 헤드라인 2줄 이하, 글자 크기 수, 대비, 가로 넘침, 글자 위 겹침, 사진 수 등입니다.
- 스크린샷을 보고 두 차례 고쳤습니다. 히어로 아래 면 재배치, 소개 문장 속 사진 확대, 칼럼 사진 고정, 진료시간 사진 위치, 모바일 헤더 한 줄 정리, FAQ 칸 여백입니다.
- 치아백과 용어 클릭, 영상 반복 재생, 오늘 요일 강조, 모바일 메뉴가 동작하고 콘솔 오류가 없는 것을 확인했습니다.

## 6. 반영 전에 확인할 것

- **사진·영상:** 원본 사이트(yidoinsight.com)에 올라와 있는 병원 촬영본을 잘라서 썼습니다. 실제 반영 때는 고해상도 원본으로 바꿔 주세요.
- **새로 쓴 문구:** 용어 뜻풀이는 원본 치아백과 문장을 바탕으로 쉽게 다듬었습니다. 히어로 소개 문장, 진료 방식 문단, 의료진 요약 3개, FAQ 답변 일부도 새로 썼으니 의료진 확인이 필요합니다.
- **"원내 기공실":** 원본 저널의 "원내 기공실, 보철물 뒤의 사람과 과정" 글을 근거로 넣었습니다.
- **공휴일:** 오늘 진료 상태는 요일만 봅니다. 공휴일 휴진은 따로 연결해야 합니다.
- **한이연 교정원장 사진:** 원본 사이트에 없어 이번 페이지에는 쓰지 않았습니다.
- **링크:** 모두 원본 사이트의 실제 경로입니다. 지도 링크는 네이버 지도 검색으로 연결됩니다.
