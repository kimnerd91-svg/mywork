# 서울이도치과 닥터인사이트 · 메인 리뉴얼 시안 v3 (3종)

같은 콘텐츠와 사내 setting.css 체계로 만든 세 가지 톤의 메인 페이지 시안입니다. 브라우저에서 `index.html`을 열면 세 시안을 고를 수 있습니다.

| 폴더 | 톤 | 한 줄 요약 |
|---|---|---|
| `a/` | A · Clinic White | 밝고 깨끗한 프리미엄. 반반 분할 히어로에 실제 상담 영상, 정돈된 정보 타일 |
| `b/` | B · Night Studio | 다크 하이엔드. 브랜드 필름 B-roll 풀블리드, 샴페인 골드 포인트, 원내 기공실 강조 |
| `c/` | C · Lounge | 따뜻한 호텔 라운지. 아이보리·월넛·세이지, 아치형 사진, 둥근 면 |

각 폴더에는 같은 구성의 6페이지가 있습니다.

| 파일 | 페이지 |
|---|---|
| `index.html` | 메인 |
| `knowledge.html` | 치아백과 목록 (검색 + 분야 필터 + 용어 23개 + 함께 읽기 경로) |
| `knowledge-implant.html` | 치아백과 상세 · 치과임플란트 (목차, 구조 도식, 비교표, 상담 질문) |
| `column.html` | 원장 칼럼 상세 · 고성민 대표원장 |
| `doctors.html` | 의료진 4인 + 글 작성 원칙 |
| `visit.html` | 진료시간·오시는 길 (실시간 진료 상태, 교통, 동네별 안내, 첫 방문 체크리스트, FAQ) |

메뉴와 페이지 안 링크는 시안 안에서 서로 이어집니다. 시안에 없는 페이지(다른 용어 상세, 다른 칼럼 등)는 원본 사이트로 연결됩니다.

미리보기는 `previews/`에 `{테마}-{페이지}-fold|full|mobile-fold.jpg` 형식으로 들어 있습니다.

## 작업 순서 (사내 스킬 파이프라인 `dental-design-pipeline`)

1. **레퍼런스 조사:** Tend(hellotend.com), Aman(aman.com), Framer 치과 템플릿(Dentalle, dentale)을 실제로 캡처하고 무드만 참고했습니다.
2. **기준 문서:** `medinmedi-design-md`로 `DESIGN.md`를 9섹션 형식으로 썼습니다. 테마별 색 토큰과 WCAG 대비 계산값이 들어 있습니다.
3. **섹션 구성:** `dental-site-sections` 표준 순서를 따랐습니다. 메인 비주얼(H1에 지역명), 빠른 검색, 치아백과, 원장 칼럼, 진료 공간, 의료진, 진료시간·오시는 길(NAP), FAQ(`<details>`), 푸터 순서이고, 의료광고법 체크도 거쳤습니다.
4. **제작:** `setting-css` 규칙을 지켰습니다. ① setting.css 유틸 → ② Bootstrap 5 → ③ 별도 파일 `css/insight.css` 순서로 스타일을 적용하고, 인라인 style은 쓰지 않았습니다(애니메이션 순서용 `--d` 변수만 예외).
5. **검수:** `impeccable` critique → polish, 모션은 `review-animations` 기준으로 점검했습니다.
6. **시각 검증:** 메인은 1440 / 992 / 375px, 서브는 1440 / 375px 캡처를 찍고 깨진 이미지·콘솔 오류·가로 넘침을 확인했습니다(모두 0). 예약·전화 CTA, 검색, 모바일 메뉴 동작도 확인했습니다.

## 구조

```
yidoinsight-v3/
├─ index.html              시안·페이지 선택
├─ a/ b/ c/                테마별 6페이지 (메인 + 서브 5)
├─ build.py                메인 페이지 콘텐츠·구성
├─ sub.py                  서브 5종 + 테마 폴더 출력 → python3 sub.py
├─ DESIGN.md               기준 문서
├─ css/setting.css         사내 유틸리티 프레임워크 (원본 그대로)
├─ css/insight.css         보조 CSS: 테마 토큰 + 컴포넌트 + 모션 (번호 붙은 블록 단위)
├─ js/insight.js           헤더·메뉴·등장 모션·치아백과 검색·오늘 진료 상태
├─ assets/img|video        병원 실사 사진, 상담 루프 영상, 브랜드 필름 B-roll 루프
└─ previews/               캡처
```

**테마 전환 방식:** `<body data-theme="a|b|c">` 하나로 바뀝니다. setting.css 변수 이름(`--main-color`, `--point`, `--light`, `--dark`…)은 그대로 두고 `insight.css` [01] 블록에서 값만 덮어씁니다.

## 공통 기능

- **치아백과 빠른 검색:** 용어 20개를 대상으로, 입력하는 즉시 결과가 나옵니다. 가중치는 용어명 > 키워드 > 분류 > 설명 순입니다.
- **오늘 진료 상태:** 한국 시간 기준으로 진료 중·점심시간·마감·휴진을 자동 표시하고, 진료시간표의 오늘 줄을 강조합니다.
- **모바일 하단 고정 CTA:** 전화 상담 / 네이버 예약
- **등장 모션:** 한 번만 실행되고, 스크립트가 실패해도 내용이 숨지 않습니다. "동작 줄이기" 설정을 켜면 이동은 빠지고 투명도 변화만 남습니다.

## 검수에서 고친 것

- **impeccable:**
  - 제목 위 영문 라벨을 모두 제거했습니다.
  - B의 제목 단계 건너뜀(h1 → h3)을 바로잡았습니다.
  - 검색창 안내 문구 대비를 보정했습니다.
  - Montserrat을 Pretendard로 통일했습니다.
  - 포커스 링을 테마 색으로 바꾸고, 텍스트 선택 색을 지정했습니다.
- **review-animations:**
  - setting.css 버튼의 `transition: all`을 속성 지정으로 바꿨습니다.
  - 헤더·FAQ 전환을 250ms 이하로 줄였습니다.
  - 터치 기기에서는 hover 이동을 끕니다.
  - 등장 간격을 70ms로 줄였습니다.
- **오탐으로 판단해 그대로 둔 것:**
  - 섹션 "cramped-padding": 여백을 setting.css 클래스로 주는데 정적 분석이 그 클래스를 읽지 못한 것입니다.
  - C의 "크림 바탕": 요청하신 따뜻한 라운지 톤입니다.
  - setting.css 안의 `u-input`/`u-glow` 발광: 시안에서 쓰지 않는 클래스입니다.

## 서브페이지 작업 메모

- 본문은 원본 사이트의 실제 글을 그대로 썼습니다(치아백과 목록·임플란트 상세, 고성민 원장 칼럼, 의료진, 방문 안내 FAQ). 칼럼은 원문을 일부 줄였습니다.
- 서브페이지에서도 impeccable 검출기를 돌렸고, C 의료진 페이지의 대비 1건을 고쳤습니다.
- 18페이지 × 2폭 렌더에서 가로 넘침·깨진 이미지·콘솔 오류·잘못된 링크는 모두 0건입니다.
- setting.css가 p·ul·h의 여백을 `!important`로 지우는 문제가 있어, 본문 영역에서만 되살렸습니다(insight.css [27]).

## 반영 전에 확인할 것

- **새로 쓴 문구:** 진료 공간 설명 3줄, B의 "듣기·설명·결정" 문단, FAQ 마지막 문항(주차·야간)은 원본 사이트 정보를 바탕으로 새로 썼습니다. 의료진 확인이 필요합니다.
- **한이연 교정원장 사진:** 원본 사이트에 없어서 이름 카드로 대신했습니다.
- **사진·영상:** 원본 사이트의 병원 촬영본을 잘라 썼습니다.
  - B 배경 영상은 브랜드 필름에서 자막 없는 구간 4개(기구, 보철 작업, 기공실, 로고 사인)를 이어 만들었습니다.
  - 실제 반영 때는 원본 고해상도 파일로 바꿔 주세요.
- **공휴일:** 오늘 진료 상태는 공휴일 휴진을 판단하지 못합니다.
- **퍼블리싱:** 그누보드 단일 PHP로 옮길 때는 `build.py`의 콘텐츠 블록과 `insight.css`를 그대로 쓰면 됩니다.
