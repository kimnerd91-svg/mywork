## 3. Typography Rules

- **한글:** Pretendard (setting.css가 이미 import). 대체 폰트는 Apple SD Gothic Neo, Noto Sans KR, Malgun Gothic.
- **테마별 제목 서체**
  - A: Pretendard 700, 자간 -0.03em
  - B: 제목 Pretendard 300(가는 굵기), 큰 숫자·영문은 Montserrat 300
  - C: 제목 Noto Serif KR 500 (setting.css의 `u-notoserif`), 본문은 Pretendard
- **크기 (setting.css `t-fs-*` / `c-fs-*` 사용)**

| 용도 | PC | 모바일(-sm) | 행간 |
|---|---|---|---|
| 히어로 H1 | `t-fs-72`~`80` (A·C), B는 별도 96px | `t-fs-36-sm` | 1.15–1.2 |
| 섹션 H2 | `t-fs-48` | `t-fs-30-sm` | 1.25 |
| 카드 H3 | `t-fs-24` | `t-fs-20-sm` | 1.35 |
| 리드 문단 | `c-fs-20` | `c-fs-17`→`c-fs-16-sm` | 1.65 |
| 본문 | `c-fs-17` 상당 (17px) | 16px | 1.7 |
| 캡션·라벨 | `c-fs-14` | `c-fs-13` | 1.5 |

- 본문 한 줄은 40–48자 이내 (`max-width: 36em`).
- 제목은 2줄을 넘기지 않는다. 넘치면 카피를 줄인다.

## 5. Layout Principles

- 컨테이너: `u-1440` (최대 1440px, 1440px 이하에서 좌우 20px). PC에서는 추가 좌우 여백 `clamp(20px, 4vw, 64px)`를 둔다.
- 섹션 위아래: `u-py-140 u-py-80-sm` (140px → 80px). 섹션 안 제목과 본문 사이 `u-mb-48`, 카드 사이 `u-gap-24`.
- 그리드: 3·4열은 `g-cols-3`/`g-cols-4` → 태블릿 `-md` 2열 → 모바일 `-sm` 1열. 반반 분할은 Bootstrap `row`/`col-lg-6`.
- 리듬: 섹션 사이 간격은 섹션 안 어떤 간격보다 크게 한다. 카드 안쪽 여백은 최소 24px(모바일 20px).
- 터치 영역은 최소 44px.

## 6. Depth & Elevation

- 그림자는 쓰지 않는다. 떠 있는 것(드롭다운 메뉴, 모바일 하단 CTA 바, 스크롤 시 헤더)만 `shadow-soft` 수준을 허용한다.
- 면 구분은 바탕 단계(`--bg-color` → `--light`/`--light2`)로만 한다.
- 레이어 순서: 콘텐츠 < 헤더(`z-header`) < 모바일 CTA 바 < 메뉴 드롭다운 < 모달(`z-modal`)

## 7. Do's and Don'ts

**Do**
- 실제 원내·원장 사진과 영상을 크게 쓴다.
- 진료시간은 표로 보여주고 야간·휴진을 강조한다. 주소·전화·주차·교통은 텍스트로 쓴다.
- 각 섹션 첫 문장은 떼어 읽어도 말이 되게 쓴다 (GEO).
- 사실은 병원 사이트에 있는 것만 쓴다.

**Don't**
- 스톡 미소 사진, 과한 그라데이션, 네온 색
- 최상급·보장 표현: 최고, 최초, 유일, 1위, 완벽, 100%, 통증 없는, 평생, 부작용 없는
- 타 병원 비교, 환자 후기 노출, 동의·부작용 고지 없는 전후사진
- 비급여 가격, 할인 이벤트 문구 (형님 확인 전)

## 8. Responsive Behavior

- 992px 이하(`-sm`): 1열 전환, 히어로 사진을 텍스트 아래로, 헤더 메뉴는 햄버거 메뉴로
- 모바일 하단 고정 CTA 바: 전화 / 네이버 예약 (높이 64px + safe-area)
- 이미지 크롭: 히어로는 인물 얼굴이 잘리지 않게 `object-position` 지정. 카드 사진은 4:3, 의료진 4:5 고정
- B 다크 히어로 영상은 모바일에서도 재생하되 `poster`를 먼저 보여준다. 동작 줄이기 설정 시 정지

## 9. Agent Prompt Guide

1. 스타일은 setting.css 유틸 클래스 → Bootstrap 5 클래스 → `css/insight.css`(별도 파일) 순서로만 쓴다. 인라인 style 금지.
2. 테마는 `<body data-theme="a|b|c">` 하나로 바꾸고, 테마 차이는 `insight.css`의 토큰 덮어쓰기로만 낸다.
3. 실제 사진·영상(`assets/`)만 쓰고, 문구는 의료광고법 체크를 통과한 것만 쓴다.
4. 섹션 순서: 메인 비주얼 → 빠른 검색 → 치아백과 카테고리 → 원장 칼럼 → 진료 공간 → 의료진 → 진료시간·오시는 길 → FAQ → 푸터.
5. 퍼블리싱 단계에서는 그누보드 단일 PHP 파일로 옮긴다. 이번 시안은 정적 HTML이다.
